# Carpe Diem — Sito Vetrina

Sito web elegante e minimal per **Carpe Diem Food & Lounge** (Rovereto).
Una sola pagina, tutto incluso in `index.html`. Nessuna installazione richiesta.

## Come vederlo
Fai doppio clic su `index.html` — si apre nel browser.

## Le foto (già inserite)
Le immagini sono nella cartella `images/`. Per sostituirne una, basta rimpiazzare
il file mantenendo lo **stesso nome**:

| File                    | Dove appare                                  |
|-------------------------|----------------------------------------------|
| `images/hero.jpg`       | Sfondo grande in cima alla pagina            |
| `images/ambiente.jpg`   | Sezione "Il Locale"                          |
| `images/eventi.jpg`     | Sezione "Eventi" (+ una tessera in gallery)  |
| `images/gallery-1.jpg` → `images/gallery-11.jpg` | Mosaico della gallery       |

La gallery è un mosaico asimmetrico: alcune tessere sono grandi il doppio in
verticale o in orizzontale (definito nel codice dalle classi `tall`, `wide`, `big`).
Cliccando una foto si apre ingrandita (lightbox).

Consiglio qualità: le foto scaricate da Instagram sono a 640px (limite pubblico).
Per la massima nitidezza sostituiscile con gli originali in alta risoluzione,
stesso nome file.
