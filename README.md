# Carpe Diem — Food & Lounge

Sito vetrina del **Carpe Diem Food & Lounge** di Rovereto (TN).
Sito statico, elegante e responsive: nessuna build necessaria.

## Pagine
- `index.html` — home (hero, il locale, menù in sintesi, eventi, gallery, contatti)
- `menu.html` — menù completo (aperitivi, cocktail, birre, distillati, cucina)

## Sviluppo locale
Apri `index.html` nel browser, oppure servi la cartella:

```bash
python3 -m http.server 8000
# poi apri http://localhost:8000
```

## Immagini
Le foto sono in `images/`. Per sostituirne una, mantieni lo stesso nome file.
